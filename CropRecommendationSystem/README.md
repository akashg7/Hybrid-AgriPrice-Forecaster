# Hybrid Crop Recommendation System

This module bridges the agronomic (biological) conditions with the economic (market price) models of the `Hybrid-AgriPrice-Forecaster`.

## 📦 Setup Instructions

1. **Download the Kaggle Dataset**:
   Since Kaggle requires an authenticated account to download datasets, please download the CSV from the link below manually:
   👉 **[Kaggle: Crop and Soil Dataset](https://www.kaggle.com/datasets/shankarpriya2913/crop-and-soil-dataset/data)**

2. **Place the Data**:
   Extract the downloaded zip, grab the CSV file (it usually contains N, P, K, pH, Temperature, Rainfall, and Crop Type), and paste it exactly here:
   `/Users/karthikreddy/Desktop/Hybrid-AgriPrice-Forecaster/CropRecommendationSystem/crop_and_soil_dataset.csv`

## 🚀 How to Run

### 1. Train the Biological Crop Model
This uses a Gradient Boosting Classifier (`LightGBM`) to learn the relations between Soil/Weather and the required Crop.
```bash
cd /Users/karthikreddy/Desktop/Hybrid-AgriPrice-Forecaster/CropRecommendationSystem
python train_crop_model.py
```
*Artifacts will be saved to your `models/` directory alongside your price predictor.*

### 2. Infer the Most Profitable Crop
Use the recommender to tell you what to grow in a specific Mandi based on the local weather/soil, and what your estimated return would be!

```bash
# Example Run: Testing for Pune soil conditions
python profitable_crop_recommender.py --mandi "Pune" --n 90 --p 42 --k 43 --ph 6.5 --temp 25 --humidity 80 --rainfall 200
```

### 🧠 How it Works
1. It takes the **N, P, K, pH, Weather** features and feeds them into the Kaggle trained classifier.
2. The classifier spits out the **Top 3 biologically viable crops** for that specific soil.
3. It takes those 3 crops and queries the **14-day price forecasts** generated by your core LightGBM/Moirai pipeline.
4. It compares the peak selling price of the 3 feasible crops and outputs the **single best crop** that maximizes profit!
