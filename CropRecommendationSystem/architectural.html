📂 Data Source

Kaggle Crop Recommendation dataset (archive.zip) with 2200 samples across 22 crop types. Features: N, P, K, temperature, humidity, pH, rainfall.

⚙️ Feature Engineering

Expands 8 raw columns into 45 features: NPK ratios & products, nutrient dominance flags, climate interactions (heat index, aridity), pH squared & deviation, rainfall log transform, regime binning, z-scores.

🤖 Model Training

Dual-model benchmark: RandomForest (99.55%) vs LightGBM (98.64%). Naive baseline at 4.5%. 5-fold stratified cross-validation. Automatic best model selection.

📊 Evaluation Suite

Per-class precision/recall/F1, confusion matrices, feature importance ranking (top: humidity, k_ratio, heat_index). Full test predictions exported as CSV.

🖥️ Dashboard (app.py)

Streamlit UI with real-time inference. User adjusts 7 sliders → pipeline engineers 45 features on-the-fly → model outputs crop probabilities across all 22 classes.
