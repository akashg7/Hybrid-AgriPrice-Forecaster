Exploratory Data Analysis (EDA) on the Crop Recommendation Dataset

The Exploratory Data Analysis for the crop recommendation system was conducted to understand the underlying distributions, 
class balances, and relationships between the 7 original agronomic features (Nitrogen, Phosphorous, Potassium, Temperature, 
Humidity, pH, and Rainfall) and the 22 target crop classes.

Below are the key EDA findings and the resulting strategy implemented in the project:

1. Perfect Class Balance & No Missing Values
   - Finding: The core dataset consists of exactly 2,200 observations, perfectly balanced with 100 samples per crop class.
   - Conclusion: This flawless class distribution ensures no inductive bias favoring a majority class, which allows tree-based 
   models (LightGBM, Random Forest) to evaluate all classes fairly without the need for synthetic oversampling (like SMOTE). 
   There were also no missing values necessitating complex imputation.

2. Disjoint vs. Overlapping Parameter Spaces
   - Finding (Clustering Analysis): Scatter plots and clustering demonstrated that fundamentally unrelated crops occupy distinctly 
   disjoint parameter spaces. For instance, Apples and Rice share virtually no overlap along the humidity and rainfall axes.
   - Finding (Overlap): Conversely, physiologically similar crops (e.g., legumes and cereals) exhibited significant overlap in 
   their parameter ranges.
   - Conclusion: Relying purely on raw continuous values (e.g., raw NPK amounts) is insufficient for drawing a sharp decision 
   boundary between overlapping crops. This highlighted the absolute necessity of deep, non-linear feature extraction.

3. Nutrient Dominance and Ratios
   - Finding: Analyzing the macronutrients (N, P, K) individually did not clearly differentiate crops, since overall soil richness 
   varied across regions.
   - Conclusion: EDA revealed that the *ratios* of nutrients and which nutrient is globally dominant are much stronger predictors 
   than raw amounts. This led to engineering features like `n_ratio`, `p_ratio`, and importantly, the `dominant_nutrient` marker 
   (whether N, P, or K is the highest). Furthermore, a `nutrient_balance` standard deviation metric was created to quantify whether a 
   soil is specialized or balanced.

4. Climate and pH Interaction Profiling
   - Finding: Continuous climate variables often have thresholds rather than linear relationships with crop viability 
   (e.g., rainfall above a certain threshold changes the biome drastically, while a change from 200mm to 210mm might be negligible).
   - Conclusion: As a result of this EDA, continuous features were divided using categorical binning. The project implemented 
   `rainfall_regime` (dry to wet bins), `ph_regime` (acidic, neutral, alkaline), and `temp_regime`. Additionally, 
   interacting variables were combined into logical agronomic proxies such as an `aridity_index` (temperature / rainfall) 
   and `heat_index` (temperature * humidity / 100.0).

In summary, the EDA directly informed the feature engineering pipeline (`build_features.py`), expanding the 7 raw features 
into over 40 highly predictive composite indicators that subsequently allowed the LightGBM classifier to achieve a >99% macro-F1 score.
